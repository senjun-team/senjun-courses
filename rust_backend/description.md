Вы научитесь писать бекенд на Rust с помощью Axum - веб-фреймворка от команды Tokio. Пройдёте путь от первого «Hello, World!» до полноценного REST API с базой данных, аутентификацией и тестами.

Курс подойдёт тем, кто уже знаком с основами Rust и хочет перейти от небольших программ и CLI-утилит к веб-разработке.
